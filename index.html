Cara pakai

  • Seret meja untuk memutar, gulir untuk mendekat, klik kanan lalu seret untuk menggeser.
  • Tombol Tambah di kiri menaruh PC, laptop, switch, router, atau server baru. Seret perangkat untuk memindahkannya.
  • Klik tombol power di perangkat untuk mematikan atau menyalakannya.
  • Klik port kosong, lalu port di perangkat lain, untuk memasang kabel. Klik kabel untuk mencabutnya.
  • Klik paket biru untuk membuka header-nya lapis demi lapis.
